# 🦇 Dark Mode - Portal e Agenda Cultural

Este projeto é uma plataforma web desenvolvida **sob demanda para um cliente**, focada em gerenciar e exibir conteúdos do cenário underground. O sistema funciona como um portal completo, integrando notícias, uma agenda de shows interativa e áreas de interação com a comunidade.

## Sobre o Projeto

O objetivo principal desta aplicação é oferecer uma experiência imersiva e responsiva (com forte identidade visual *Dark Mode*) para os usuários acompanharem eventos e novidades. 

**Principais Funcionalidades:**
* **Agenda de Shows Dinâmica:** Calendário interativo e personalizado para facilitar a busca por eventos e compra de ingressos.
* **Portal de Notícias:** Publicação de matérias com categorização e sistema de destaques.
* **Interação:** Sistema de comentários em notícias.
* **Monetização:** Espaços gerenciáveis para anúncios (Ads) integrados ao layout.
* **Painel Administrativo:** Gestão completa de conteúdo (CRUD de eventos, notícias, categorias, anúncios e moderação de comentários) de forma intuitiva.

## Tecnologias Utilizadas

A stack foi escolhida para garantir alta performance no Front-end e facilidade de manutenção e segurança no Back-end:

**Front-end:**
* [Vue.js 3](https://vuejs.org/) (Composition API)
* [Tailwind CSS](https://tailwindcss.com/) (Estilização e responsividade)
* [PrimeVue](https://primevue.org/) (Componentes de UI, como o Calendário da Agenda)

**Back-end & Painel:**
* [Laravel 11](https://laravel.com/) (API e lógica de negócios)
* [Filament PHP](https://filamentphp.com/) (Painel Administrativo poderoso e ágil)
